# AI-Based Smart Complaint Management System

A MERN Stack based AI-powered Complaint Management System developed for ESE Examination (AI Driven Full Stack Development).

## Features

### Authentication & Security
- User Signup
- User Login
- JWT Authentication
- bcrypt Password Hashing
- Protected Routes

### Complaint Management
- Complaint Registration
- Complaint Tracking
- Complaint Status Update
- Delete Complaint
- Filter Complaints by Category
- Search Complaints by Location

### AI Features
- Complaint Priority Detection
- Responsible Department Recommendation
- Complaint Summary Generation
- Automatic Response Generation

## Tech Stack

### Frontend
- React.js
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

### AI Integration
- OpenRouter API
